# BankCore — Frontend (React + Vite + Tailwind)

Современный финтех-интерфейс для Java Spring Boot ядра **BankCore**.

## Стек
- React 18 + Vite 6
- Tailwind CSS 3 (тёмная «банкирская / cyberpunk» тема)
- Lucide React (иконки)

## Как запустить

1. Убедись, что Backend BankCore запущен на `http://localhost:8080`.
2. Поставь зависимости и запусти dev-сервер:

```bash
cd frontend
npm install
npm run dev
```

Dev-сервер стартует на **http://localhost:5147**.

## Прокси и CORS

CORS на бэкенде не настроен — поэтому Vite-проксирует все запросы `/api/*` на
`http://localhost:8080` (см. `vite.config.js`). Браузер ходит на тот же origin,
что исключает проблемы с CORS. **Бэкенд не изменён ни в одном файле.**

## Сборка для прод

```bash
npm run build   # → dist/
```

Собранный статический фронтенд нужно раздавать с проксированием `/api` на `:8080`
(например, nginx: `location /api { proxy_pass http://localhost:8080; }`).

## Структура

```bash
src/
├── main.jsx                 # точка входа, провайдеры (логи, тосты)
├── App.jsx                  # роутинг по вкладкам, общие стейты, поллинг статуса
├── index.css                # токены дизайна Tailwind, анимации, скроллбары
├── lib/
│   ├── api.js               # обёртка над REST API бэкенда
│   ├── format.js            # форматирование денег, времени, ID, тоны статусов
│   ├── logger.jsx           # глобальная шина логов для live-терминала
│   └── hooks.js             # useInterval / useNow
└── components/
    ├── Layout.jsx           # сайдбар + часы + статус API
    ├── AccountsPanel.jsx    # дашборд счетов: карточки, метрики, создание
    ├── CreateAccountForm.jsx# форма создания счета
    ├── TransferPanel.jsx    # переводы: выбор счетов, сумма, сводка
    ├── AdminPanel.jsx       # тумблер переводов, метрики локов, консоль аудита
    ├── Terminal.jsx         # live-терминал логов с фильтрами и поллингом аудита
    ├── toast.jsx            # красивые уведомления
    └── ui.jsx               # примитивы: Modal, Switch, MetricCard, Badge, StatusPill
```

## Возможности

- Список счетов, суммарный/средний баланс, создание счета.
- Переводы между счетами с валидацией, превью комиссии, автообновлением балансов.
- Лок-флаг переводов (переключение + поллинг статуса каждые 3 с).
- Метрики: активные локи, созданные локи.
- Консоль аудита счёта (асинхронная сводка).
- Live-терминал: реальные события приложения + поллинг аудита + heartbeat,
  фильтры по уровню, пауза, очистка, автоскролл.
